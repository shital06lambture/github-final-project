# Simple Interest Calculator

This project calculates simple interest using the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal amount
- Rate of interest
- Time period in years

## Example

Principal = 1000  
Rate = 5%  
Time = 2 years

Simple Interest = (1000 × 5 × 2) / 100 = 100

## Output

The simple interest is 100.

## How to Run

Run the `simple-interest.sh` script in a Bash terminal and enter the required values.
